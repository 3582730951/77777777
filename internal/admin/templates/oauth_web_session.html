提交完整 Web Session 材料
Session JSON 可以直接从 /api/auth/session 获取；Cookie 需要从 DevTools Network 复制完整请求头。

1. 打开并确认已登录 ChatGPT

→ 打开 chatgpt.com

2. 获取 Session JSON 和 Cookie header

在 DevTools Network 中找到 /api/auth/session 请求：Response 复制完整 JSON 到 Session； Request Headers 复制完整 Cookie 到 Cookies。Cookie 必须包含 __Secure-next-auth.session-token 或 __Secure-next-auth.session-token.0/.1 分片。

3. 粘贴完整 session + cookie

在已登录的 chatgpt.com 里请求 https://chatgpt.com/api/auth/session，把响应 JSON 粘到 Session； 再从 DevTools Network 复制请求的完整 Cookie header 粘到 Cookies。

必须包含 __Secure-next-auth.session-token 或它的分片 cookie；否则后台无法自动刷新。
