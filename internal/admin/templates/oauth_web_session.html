提交完整 Web Session 材料
Session JSON 可以直接从 /api/auth/session 获取；Cookie 需要从 DevTools Network 复制完整请求头。

1. 打开并确认已登录 ChatGPT

→ 打开 chatgpt.com

2. 选择导入模式并获取材料

在 DevTools Network 中找到 /api/auth/session 请求：Response 复制完整 JSON 到 Session； 自动刷新模式还需要 Request Headers 的完整 Cookie；仅 Session JSON 模式会转换成 CPA/Codex auth.json 快照， 不保存 Cookie，也不会采用 refresh_token 刷新。

3. 粘贴完整 session + cookie

在已登录的 chatgpt.com 里请求 https://chatgpt.com/api/auth/session，把响应 JSON 粘到 Session； 再从 DevTools Network 复制请求的完整 Cookie header 粘到 Cookies。

需要 Session JSON 和 Cookie；后台用 Cookie 请求 /api/auth/session 更新 accessToken 和 Set-Cookie。
支持 Cookie header、curl -H Cookie、Netscape cookies.txt、JSON cookie 导出、Chrome Application Cookies 表格；必须包含 session-token 或分片 cookie。
