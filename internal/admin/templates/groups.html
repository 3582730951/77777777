路由机制说明
1. API Key 鉴权
请求携带 API Key → 匹配到对应分组 → 获得 Provider 和模型白名单
2. 协议自动检测
/v1/messages → Anthropic，/v1/chat → OpenAI，/v1beta → Gemini
任意协议都可路由到任意 Provider
3. 账号调度
P2C+EWMA 算法选出最优账号，含 Head Buffer 故障转移和"绝不放弃"策略
